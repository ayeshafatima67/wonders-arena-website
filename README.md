Purpose

The website brings information about the club’s sports, facilities, timings, coaches, membership plans, events, competitions and equipment prices together in one easy-to-navigate place.

Website Pages

- Home
- About Club
- Facilities
- Membership
- Events and Competitions
- Login / Sign up
- Help

Project Status

Phase 1 – Planning and Analysis: Completed

The project requirements, website structure and initial page designs were documented in the planning report and wireframes.

Phase 2 – Design and Front-end Implementation: Completed

All seven website pages have been implemented using HTML and CSS, with consistent navigation, shared styling and responsive layouts. The Deliverable 2 report includes desktop and mobile screenshots, code explanations and local validation results.

Technologies Used

- HTML5 — page structure and content
- CSS3 — styling and responsive layouts

How to Run

Download and extract the website ZIP, then open "index.html" in a web browser. Keep all project files and folders together so that stylesheets, images and links load correctly.
